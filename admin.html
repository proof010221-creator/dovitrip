🚨 거래주의 대상 등록

관리자가 신고 내용을 확인한 뒤 등록하는 공간입니다. 유저 메인 페이지에는 공개 사유만 표시하고, 관리자 메모는 관리자 페이지에서만 확인하는 방식으로 운영하세요.
표현 주의
메인 페이지에는 “먹튀범 확정”보다 거래주의 대상, 주의 등록 유저 같은 표현을 권장합니다. 공개 사유는 짧고 중립적으로 적는 것이 안전합니다.

🔎 거래주의 대상 검색

VIP 메인 조회 연결 예정 여기에 등록된 활성 대상만 유저 메인 페이지의 거래주의 조회에서 표시되도록 연결합니다.

📥 거래주의 일괄 붙여넣기 등록

외부 목록을 사람이 직접 확인한 뒤 그대로 붙여넣고, 미리보기에서 변환 결과를 확인한 다음 일괄 등록하세요. 외부 사이트 자동 조회는 하지 않습니다.
등록 기준
가해자 번호/고유번호는 루디스 고유번호로 저장하고, 가해자 닉네임/닉네임은 닉네임으로 저장합니다. 피해자 정보가 있으면 관리자 메모에만 남깁니다.
미리보기 붙여넣기 후 [미리보기 변환]을 누르면 저장될 형식이 표시됩니다.
